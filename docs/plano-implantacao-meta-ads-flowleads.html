2. A Arquitetura do Lead e Segmentação por Vendedor

O fluxo de dados desde o clique no Instagram até a tela do FlowLeads opera da seguinte maneira:

1
O Clique no Anúncio (Instagram / Meta Ads)

O cliente assiste a um anúncio ou post impulsionado no Instagram e clica em "Enviar Mensagem". O Meta Ads abre o WhatsApp conectando o cliente ao número vinculado àquele anúncio específico, com o token criptográfico de anúncio (CTWA).

2
O Disparo do Webhook Oficial da Meta

Quando o cliente envia a mensagem inicial no WhatsApp, a Meta dispara um webhook HTTP POST contendo:

  • metadata.display_phone_number: O número de WhatsApp da sua empresa que recebeu a mensagem (ex: 19987252090).
  • messages[0].from: O número pessoal do cliente.
  • contacts[0].profile.name: O nome de perfil do cliente no WhatsApp.
  • messages[0].referral: Objeto com o ID do Anúncio (source_id), Título do Anúncio (headline) e o Click ID (ctwa_clid).
3
O Cloudflare Worker Traduz e Encaminha

O Cloudflare Worker intercepta o webhook em microssegundos no Edge, mapeia o display_phone_number como destination_whatsapp, extrai a campanha e dispara um POST seguro para o FlowLeads.

4
O FlowLeads Roteia e Cria o Card

O FlowLeads recebe a requisição, pesquisa no banco de dados qual vendedor possui o telefone correspondente em destination_whatsapp, cria o card no Kanban na fase inicial com o nome e telefone mascarado do cliente e atribui a meta individual e o card diretamente para aquele vendedor.

Atenção Crucial ao Turbinar pelo Instagram: Ao usar o botão "Turbinar" diretamente pelo app do celular do Instagram, a Meta força o direcionamento apenas para o WhatsApp principal do perfil. Para conseguir segmentar vendedores diferentes por campanha, é fundamental criar ou configurar os anúncios pelo Meta Ads Manager (Gerenciador de Anúncios no computador), selecionando o post existente e escolhendo o número de destino em cada Conjunto de Anúncios.

3. Passo a Passo: Construção do App no Meta for Developers

1
Criar o Aplicativo Empresarial

Acesse developers.facebook.com com a conta administradora do Facebook da empresa:

  • Clique em Meus Aplicativos > Criar Aplicativo.
  • Selecione o tipo de aplicativo: Empresa (Business) ou Outro.
  • Defina o Nome de Exibição: FlowLeads Webhook Bridge.
  • Selecione a sua Conta Empresarial do Meta Business Manager (Grupo Mário Neto) e clique em Criar.
2
Adicionar o Produto WhatsApp

No painel inicial do aplicativo recém-criado:

  • Role a página até o card WhatsApp e clique em Configurar.
  • Vincule a sua Conta do WhatsApp Business (WABA) à qual pertencem os números de WhatsApp dos seus vendedores.
3
Configurar o Webhook no WhatsApp

No menu lateral esquerdo, clique em WhatsApp > Configuração:

  • Localize o painel Webhooks e clique em Editar.
  • URL de Retorno (Callback URL): https://flowleads-crm.fbdv1202.workers.dev
  • Token de Verificação (Verify Token): atlas_flowleads_2026
  • Clique em Verificar e Salvar. A Meta fará um teste GET e o Worker responderá instantaneamente com sucesso.
  • Na lista de campos de Webhook, localize messages e clique em Assinar (Subscribe).
4
Gerar o Token Permanente de Sistema (System User)

Para enriquecer os leads com o nome exato da campanha via Graph API:

  • Acesse o Meta Business Suite > Configurações do Negócio > Usuários do Sistema.
  • Adicione um usuário chamado FlowLeads System User com função de Administrador.
  • Atribua o seu App e a conta do WhatsApp a esse usuário com controle total.
  • Clique em Gerar Token e selecione as permissões: whatsapp_business_messaging, whatsapp_business_management e ads_read.
  • Copie o token gerado. Ele nunca expira.

4. As Requisições na Meta Graph API

Duas requisições principais ocorrem no ecossistema:

A. O Webhook Inbound (Recebimento Automático)

Disparado pela Meta para o Cloudflare Worker a cada nova conversa de anúncio:

POST https://flowleads-crm.fbdv1202.workers.dev Content-Type: application/json { "object": "whatsapp_business_account", "entry": [{ "changes": [{ "field": "messages", "value": { "metadata": { "display_phone_number": "19987252090" }, "contacts": [{ "profile": { "name": "Nome do Lead" } }], "messages": [{ "from": "5519999998888", "text": { "body": "Olá, vi o anúncio no Instagram!" }, "referral": { "source_type": "ad", "source_id": "120205839201920", "headline": "Promoção Óculos Multifocais", "ctwa_clid": "ARBDb_zN9k3X4..." } }] } }] }] }

B. O Enriquecimento de Campanha (Cloudflare -> Graph API)

O Worker consulta os dados da campanha no Meta Ads Manager usando o source_id do anúncio:

GET https://graph.facebook.com/v21.0/{source_id}?fields=id,name,adset{id,name,campaign{id,name}}&access_token={META_ACCESS_TOKEN}

5. Código Oficial do Cloudflare Worker (Copy & Paste Ready)

Este é o código exato em execução no seu Cloudflare Worker em https://flowleads-crm.fbdv1202.workers.dev:

export default { async fetch(request, env, ctx) { const url = new URL(request.url); // 1. Handshake de Validação do Webhook (GET da Meta) if (request.method === "GET") { const mode = url.searchParams.get("hub.mode"); const token = url.searchParams.get("hub.verify_token"); const challenge = url.searchParams.get("hub.challenge"); const expectedToken = env.META_VERIFY_TOKEN || "atlas_flowleads_2026"; if (mode === "subscribe" && token === expectedToken) { return new Response(challenge, { status: 200, headers: { "Content-Type": "text/plain" } }); } return new Response("Forbidden: Invalid Verify Token", { status: 403 }); } // 2. Recepção de Mensagens de Leads (POST da Meta) if (request.method === "POST") { try { const body = await request.json(); ctx.waitUntil(processWebhook(body, env)); return new Response("EVENT_RECEIVED", { status: 200 }); } catch (err) { return new Response("Bad Request", { status: 400 }); } } return new Response("Method Not Allowed", { status: 405 }); } }; async function processWebhook(body, env) { if (body.object !== "whatsapp_business_account") return; for (const entry of (body.entry || [])) { for (const change of (entry.changes || [])) { if (change.field !== "messages" || !change.value) continue; const value = change.value; const displayPhoneNumber = value.metadata?.display_phone_number || ""; const contacts = value.contacts || []; const messages = value.messages || []; for (const msg of messages) { if (msg.type !== "text" && !msg.referral && !msg.text) continue; const referral = msg.referral; const senderPhone = msg.from || ""; const contact = contacts.find(c => c.wa_id === senderPhone) || contacts[0]; const contactName = contact?.profile?.name || "Lead WhatsApp"; const messageText = msg.text?.body || ""; let marketingData = { is_ad_lead: referral?.source_type === "ad", ad_id: referral?.source_id || null, campaign_name: referral?.headline || "Campanha Meta Ads (WhatsApp)", headline: referral?.headline || null, ctwa_clid: referral?.ctwa_clid || null }; // Enriquecimento opcional via Graph API caso haja Token if (marketingData.is_ad_lead && env.META_ACCESS_TOKEN && env.META_ACCESS_TOKEN.length > 20) { try { const res = await fetch(`https://graph.facebook.com/v21.0/${marketingData.ad_id}?fields=id,name,adset{name,campaign{name}}&access_token=${env.META_ACCESS_TOKEN}`); if (res.ok) { const meta = await res.json(); marketingData.campaign_name = meta.adset?.campaign?.name || marketingData.campaign_name; } } catch (e) { console.warn("Falha Graph API:", e); } } // Despacho unificado para o FlowLeads CRM const flowleadsUrl = env.FLOWLEADS_WEBHOOK_URL || "https://flowleads-crm-blush.vercel.app/api/webhooks/inbound"; await fetch(flowleadsUrl, { method: "POST", headers: { "Content-Type": "application/json", "User-Agent": "FlowLeads-Worker/2.0" }, body: JSON.stringify({ name: contactName, phone: senderPhone, destination_whatsapp: displayPhoneNumber, campaign_name: marketingData.campaign_name, platform: "META ADS / WHATSAPP CTWA", notes: `[Mensagem WhatsApp]: "${messageText}"\nAd ID: ${marketingData.ad_id || "N/A"}` }) }); } } } }
